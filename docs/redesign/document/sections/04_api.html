6.4enskit.algorithms.eki

The current EKI contract (docs/eki-contract.md) carries over almost entirely, including the step's operations, the driver order, the key-split arity, history records, the status constants and EKIError. What changes:

  • the state holds an Ensemble, so parameters can be several named blocks;
  • the update is any kalman.UpdateRule, which is required, and an approximation= hook selects the covariance estimator;
  • localization is a method wrapper rather than a separate policy;
  • inflation and relaxation policies are shared with the EnKF (§6.6);
  • u_dim and v_dim give way to block names.
