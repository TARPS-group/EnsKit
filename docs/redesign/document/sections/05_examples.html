7Worked examples

Fifteen examples, written as notebooks so that the mathematics, a short explanation and the code sit together. Each one states its setup precisely, says when the method or API level it illustrates is the right tool, and cites the papers its methods come from. Every notebook was executed against the prototype exactly as shown, and the output under each code cell is that run's real output. The last cell of each notebook holds its checks, compared against a closed form where one exists. The notebooks ship in the documentation's examples gallery, built with nbsphinx, which is already a development dependency.
